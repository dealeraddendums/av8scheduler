PROJECT OVERVIEW
================================================================================

N4368V Aircraft Scheduler is a sophisticated web-based scheduling application 
designed specifically for shared aircraft management among multiple pilots. The 
application provides a comprehensive solution for coordinating flight bookings, 
preventing scheduling conflicts, tracking maintenance periods, and managing 
pilot communications through an intuitive calendar interface.

Published at: https://N4368V.com

The system is built on a modern tech stack featuring React for the frontend, 
Supabase for backend services, and Twilio for SMS notifications, ensuring 
real-time synchronization and reliable communication among all pilots sharing 
the aircraft.


CORE FEATURES
================================================================================

1. INTERACTIVE CALENDAR SYSTEM
   - Week, month, and day views for flexible scheduling
   - Click-to-book interface with time slot selection
   - Color-coded events by pilot for easy visual identification
   - Real-time conflict detection preventing double-bookings
   - Customizable time range (6 AM to 10 PM default)
   - Support for both 12-hour and 24-hour time formats

2. PILOT MANAGEMENT
   - Three primary pilots: Karl Hadwen, Mike Lynch, and Tom Smith
   - Each pilot assigned a unique color from sophisticated muted palette:
     * Navy (#4E5166)
     * Blue Gray (#7C90A0)
     * Tan (#B5AA9D)
     * Sage (#B9B7A7)
     * Charcoal (#747274)
   - Individual pilot profiles with contact information
   - SMS notification preferences per pilot

3. BOOKING TYPES
   
   A. Standard Flight Reservations
      - Create bookings with start/end times
      - Optional custom titles (e.g., "Training Flight", "Cross Country")
      - Notes field for additional details
      - Automatic conflict checking with existing bookings
   
   B. Maintenance Entries
      - Special booking type for aircraft maintenance
      - Displayed in red color (#ef4444)
      - BLOCKS all other bookings during maintenance period
      - Prevents pilots from scheduling conflicting flights
      - Used for scheduled inspections, repairs, and servicing
   
   C. Note / Reminder Entries
      - Informational entries displayed in yellow (#eab308)
      - Does NOT block scheduling
      - Used for reminders like:
        * "Weather check required"
        * "Hangar door may be slow"
        * "Check fuel levels before flight"
      - Pilots can still book flights during note periods

4. SMART CONFLICT DETECTION
   
   The application implements sophisticated conflict detection logic:
   
   - Maintenance bookings BLOCK everything:
     * No pilot bookings allowed during maintenance
     * No other maintenance bookings allowed (single maintenance at a time)
     * Notes are blocked during maintenance
   
   - Regular pilot bookings conflict with:
     * Other pilot bookings (prevents double-booking)
     * Maintenance periods (can't fly during maintenance)
     * Does NOT conflict with notes (notes are informational only)
   
   - Note entries:
     * Do NOT block pilot bookings
     * Do NOT block other notes
     * Only blocked by maintenance periods

5. SECURE PIN AUTHENTICATION
   - 4-digit PIN system for pilot identification
   - No complex passwords needed
   - Each pilot sets their own PIN in settings
   - Session-based authentication (stays logged in during browser session)
   - Required for creating, editing, or deleting bookings
   - Optional login for viewing calendar

6. SMS NOTIFICATION SYSTEM
   - Powered by Twilio integration
   - Automatic notifications sent to all pilots when:
     * New booking is created
     * Booking is modified
     * Booking is cancelled
   - Notifications include:
     * Pilot name
     * Date and time of booking
     * Booking title/purpose
     * Any special notes
   - Each pilot can enable/disable SMS notifications in settings
   - Support for multiple phone numbers per pilot

7. STATISTICS AND ANALYTICS
   - Real-time flight hour tracking per pilot
   - Top pilot identification by usage
   - Total bookings count
   - Collapsible stats boxes to save screen space
   - Only visible to logged-in pilots

8. USER MANAGEMENT SETTINGS
   - Comprehensive settings page accessible to logged-in pilots
   - Each pilot can update:
     * Name and email
     * Primary phone number
     * Secondary phone numbers (multiple)
     * SMS notification preferences (on/off)
     * 4-digit PIN code
     * Time format preference (12h vs 24h)
     * Timezone selection
   - Changes sync immediately across all views

  userId: string                // Pilot ID (or 'maintenance'/'note')

  userColor: string             // Display color
  startTime: string             // ISO 8601 datetime
  endTime: string               // ISO 8601 datetime
  title: string                 // Booking title/purpose
  notes?: string                // Additional details

{
  id: string                    // Unique note identifier

  note: string                  // Note content
  blocksScheduling: boolean     // Whether it blocks bookings
  createdBy: string             // Creator pilot ID
  createdByName: string         // Creator pilot name
  createdAt: string             // Creation timestamp
}


CONFLICT DETECTION LOGIC
================================================================================

The application implements a sophisticated three-tier conflict detection system:

TIER 1: MAINTENANCE BLOCKS EVERYTHING
--------------------------------------
When userId === 'maintenance':
- Blocks all pilot bookings
- Blocks all note entries
- Blocks other maintenance entries
- Creates a complete aircraft unavailability period

TIER 2: PILOT BOOKINGS
-----------------------
When userId is a regular pilot ID:
- Conflicts with other pilot bookings (prevents double-booking)
- Conflicts with maintenance periods (can't fly during maintenance)
- Does NOT conflict with notes (notes are informational)
- Validates time overlap using interval comparison

TIER 3: NOTE ENTRIES
--------------------
When userId === 'note':
- Does NOT block pilot bookings
- Does NOT block other notes
- Only blocked by maintenance periods
- Allows multiple notes on same day/time

ALGORITHM:
For each new booking, the system:
1. Fetches all existing bookings
2. Checks for blocked days (from day notes with blocksScheduling=true)
3. Iterates through existing bookings checking time overlap
4. Applies conflict rules based on booking types
5. Returns 409 Conflict error if collision detected
6. Proceeds with booking creation if no conflicts


SMS NOTIFICATION SYSTEM
================================================================================

TWILIO INTEGRATION
- Uses Twilio REST API for SMS delivery
- Requires environment variables:
  * TWILIO_ACCOUNT_SID
  * TWILIO_AUTH_TOKEN
  * TWILIO_PHONE_NUMBER
- Sends from verified Twilio phone number

NOTIFICATION TRIGGERS:

1. New Booking Created
   Message format:
   "New N4368V booking: [PILOT] on [DATE] from [START] to [END]. 
    Purpose: [TITLE]. Notes: [NOTES]"

2. Booking Updated
   Message format:
   "[PILOT]'s N4368V booking updated: [DATE] from [START] to [END]. 
    Purpose: [TITLE]"

3. Booking Cancelled
   Message format:
   "N4368V booking cancelled: [PILOT]'s flight on [DATE] from [START] 
    to [END] has been cancelled."

RECIPIENT SELECTION:
- Sends to all pilots with smsNotifications enabled
- Includes primary phone number
- Includes all secondary phone numbers
- Excludes pilot who created the booking (no self-notification)

USAGE WORKFLOW
================================================================================

FOR NEW USERS:
1. Visit https://N4368V.com
2. View calendar without logging in
3. Click "Login" button
4. Select pilot name from dropdown
5. Enter default PIN or set new PIN in Settings
6. Click time slot to create first booking

FOR CREATING FLIGHT BOOKING:
1. Login with pilot credentials
2. Navigate to Calendar view
3. Click desired time slot on calendar
4. Select your name from pilot dropdown
5. Enter title (e.g., "Training Flight")
6. Confirm start/end times
7. Add any notes
8. Click "Create Booking"
9. Receive confirmation and SMS sent to other pilots

FOR SCHEDULING MAINTENANCE:
1. Login with any pilot credentials
2. Navigate to Calendar view
3. Click time slot for maintenance period
4. Select "Maintenance" from pilot dropdown
5. Enter title (e.g., "100-hour Inspection")
6. Set maintenance duration
7. Add notes about maintenance work
8. Click "Create Booking"
9. Aircraft blocked for all pilots during this time

FOR ADDING REMINDERS:
1. Login with pilot credentials
2. Navigate to Calendar view
3. Click time slot for reminder
4. Select "Note / Reminder" from pilot dropdown
5. Enter reminder text (e.g., "Check weather")
6. Set time if specific
7. Click "Create Booking"
8. Note appears in yellow, doesn't block scheduling

FOR EDITING BOOKINGS:
1. Login as booking creator
2. Click on existing booking in calendar
3. Edit Dialog opens with current details
4. Modify times, title, or notes
5. Click "Update"
6. Confirmation shown and SMS sent

FOR CANCELLING BOOKINGS:
1. Login as booking creator
2. Click on booking in calendar
3. Click "Delete" button
4. Confirm cancellation
5. Cancellation SMS sent to all pilots

FOR UPDATING SETTINGS:
1. Login with pilot credentials
2. Click "Settings" button in header
3. Update personal information, phone, preferences
4. Change PIN if desired
5. Enable/disable SMS notifications
6. Select time format preference
7. Choose timezone
8. Click "Save Changes"
9. Return to Home
