Project Overview

N4368V Aircraft Scheduler is a sophisticated web-based scheduling application designed specifically for shared aircraft management among multiple pilots. The application provides a comprehensive solution for coordinating flight bookings, preventing scheduling conflicts, tracking maintenance periods, and managing pilot communications through an intuitive calendar interface.


The system is built on a modern tech stack featuring React for the frontend, Supabase for backend services, and Twilio for SMS notifications, ensuring real-time synchronization and reliable communication among all pilots sharing the aircraft.

Key Benefits: Zero double-booking conflicts, real-time pilot notifications, intuitive calendar interface, and secure authentication system.

Core Features

1. Interactive Calendar System

  • Week, month, and day views for flexible scheduling
  • Click-to-book interface with time slot selection
  • Color-coded events by pilot for easy visual identification
  • Real-time conflict detection preventing double-bookings
  • Customizable time range (6 AM to 10 PM default)
  • Support for both 12-hour and 24-hour time formats

3. Booking Types

✈️ Standard Flight Reservations

  • Create bookings with start/end times
  • Optional custom titles
  • Notes field for details
  • Automatic conflict checking

🔧 Maintenance Entries

  • Displayed in red color
  • BLOCKS all other bookings
  • Prevents conflicting flights
  • For inspections and repairs

📝 Note / Reminder Entries

  • Displayed in yellow color
  • Does NOT block scheduling
  • Used for reminders
  • Informational only

4. Smart Conflict Detection

Three-Tier Conflict System:
  • Maintenance: Blocks everything (all pilots, other maintenance, notes)
  • Pilot Bookings: Conflict with other pilots and maintenance, NOT notes
  • Notes: Don't block anything except during maintenance

5. Secure PIN Authentication

  • 4-digit PIN system for pilot identification
  • No complex passwords needed
  • Each pilot sets their own PIN in settings
  • Session-based authentication
  • Required for creating, editing, or deleting bookings

6. SMS Notification System

  • Powered by Twilio integration
  • Automatic notifications for new bookings, updates, and cancellations
  • Sent to all pilots with SMS enabled
  • Includes pilot name, date, time, and purpose
  • Support for multiple phone numbers per pilot

Usage Workflow

Creating a Flight Booking

  1. Login with pilot credentials
  2. Navigate to Calendar view
  3. Click desired time slot on calendar
  4. Select your name from pilot dropdown
  5. Enter title (e.g., "Training Flight")
  6. Confirm start/end times
  7. Add any notes
  8. Click "Create Booking"
  9. Receive confirmation and SMS sent to other pilots

Scheduling Maintenance

  1. Login with any pilot credentials
  2. Navigate to Calendar view
  3. Click time slot for maintenance period
  4. Select "Maintenance" from pilot dropdown (red with wrench icon)
  5. Enter title (e.g., "100-hour Inspection")
  6. Set maintenance duration
  7. Add notes about maintenance work
  8. Click "Create Booking"
  9. Aircraft blocked for all pilots during this time

Adding Reminders

  1. Login with pilot credentials
  2. Navigate to Calendar view
  3. Click time slot for reminder
  4. Select "Note / Reminder" from pilot dropdown (yellow with note icon)
  5. Enter reminder text (e.g., "Check weather")
  6. Set time if specific
  7. Click "Create Booking"
  8. Note appears in yellow, doesn't block scheduling

Security Considerations

Authentication & Authorization

  • PIN-based authentication (4 digits)
  • Session storage for logged-in state
  • Read-only access for non-logged-in users
  • Create/Edit/Delete requires authentication
  • Users can only edit their own bookings

Data Protection

  • API keys stored as environment variables
  • Service role keys never exposed to frontend
  • CORS headers configured for API security
  • Input validation on all form fields
  • Twilio credentials in protected variables
